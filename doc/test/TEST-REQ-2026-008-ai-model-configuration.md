## 2. 测试范围与依据

- 测试目标：验证供应商接入配置管理、单模型独立配置管理、三级管理范围（平台超管、租户管理员、普通用户）、内部运行读取及凭据敏感边界符合 REQ-2026-008 规范。
- 范围内：blade-ai-api、blade-ai、blade-system（用户归属与字典契约扩展）、管理 HTTP API、内部 Feign 契约、MySQL 表与字典种子。

- 验收依据：AC-001 至 AC-028、业务规则 BR-001 至 BR-010、异常流程 EX-001 至 EX-010。
