## 2. 测试范围与依据

- 测试目标：验证 Saber、gateway、blade-system、Redis 和 MySQL 组成的新认证体系用户自助注册完整链路。
- 范围内：注册开关、默认/显式租户、账号密码校验、图形验证码、注册限流、普通角色、无部门岗位、事务回滚、账号唯一性、注册回跳、登录状态、权限边界和 system 启动依赖检查。
- 范围外：邮件/短信验证、租户创建、注册审批、找回密码、实名/多因素认证和新的 C 端业务页面。
- 验收依据：需求 `AC-001` 至 `AC-034`、`BR-001` 至 `BR-012` 及详细设计。

架构决策已确认：全量切入基于 Spring Authorization Server 与网关 BFF 的新认证体系，旧 `blade-auth` 注册链路废弃；注册功能由 `blade-system` 承接公开端点，网关 BFF 白名单放行，密码直接落地 `{bcrypt}`。用例执行基线从旧 blade-auth 调整为 `blade-system` 注册端点及真实密码/BCrypt 登录闭环。
