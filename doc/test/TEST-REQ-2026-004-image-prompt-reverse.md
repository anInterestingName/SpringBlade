## 2. 测试范围与依据

- 测试目标：验证单图上传、系统分析策略、标签 Redis 快照、fast 调用、固定 JSON、租户权限、错误处理和日志安全。
- 范围内：`/blade-ai/prompt/reverse`、提示词 `SYSTEM + MANUAL` 治理、标签运行时 Feign、Redis 快照/锁、fast 正常和失败调用、响应二次校验。
- 范围外：真实模型效果主观验收以外的模型训练、批量任务、分析历史、对象存储和跨租户管理。
- 验收依据：REQ-2026-004 AC-001~AC-020、BR-001~BR-013 和详细设计风险。

准备要求：

1. 租户 A 初始化 `image_prompt_reverse`，类型 `SYSTEM`、发布方式 `MANUAL`，由管理员所有并发布 V1。
2. 租户 A 准备启用分类和标签，至少包含单选、多选及最大数量规则。
3. 租户 B 准备不同标签和独立同编码系统策略。
4. fast 使用测试 API Key 和可替换假上游；自动化测试不得访问真实付费模型。
5. Redis 使用专用 Key 前缀；只允许清理本需求前缀和测试租户生成的数据。

## 5. 专项检查

- [ ] 上传文件魔数、大小、像素、空文件和重复提交。
- [ ] 未登录、无反推权限、无 SYSTEM_MANAGE、OWN/ALL 和越租户。

- [ ] 标签 Feign 正常/Fallback、Redis 命中/失效/锁竞争/TTL。
