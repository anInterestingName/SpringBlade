## 2. 测试范围与依据

- 目标：浏览器经网关完成 OIDC 登录，网关保存 Token，并以 Access Token 调用 demo，通过 JWT 和 scope 校验。
- 历史阶段范围内（TC-001 至 TC-015）：普通启动类、内存配置、WebSession、授权码与 PKCE、TokenRelay、刷新、CSRF、本地退出和失败响应；Saber 独立 Vue 登录、授权确认、验证页面和 Vite 代理。
- 历史阶段范围外：blade-auth 兼容、真实用户/租户、业务数据权限、数据库、Redis、Nacos、Feign、集群、持久化、Saber 全量认证迁移、生产部署和全局单点退出。
- 本项修复范围（TC-016、TC-017）：现有持久化链路中的系统用户密码认证因子、OIDC auth_time、Redis 会话与 MySQL 授权编解码、再次授权/刷新和密码/scope 回归。复用既有依赖，不新增接口、配置或数据库结构，不追认整个持久化改造已验收。
- 审计、脱敏不涉及：用户未提出相关需求；仍检查响应和日志不暴露 OAuth Token、密码、密钥及授权码。
- 验收依据：本会话确定的最小 BFF 方案及现有实现；编译与静态检查不能替代运行和业务验收。
- 用户确认前阶段最小链路已通过，但没有提供全部历史失败项的逐用例复测证据。以下保留历史失败事实和缺陷，新增前端链路均待执行；不据此推断刷新、隔离、安全或页面验收已通过。

### TC-008 错误和重复授权回调

- 优先级：P1；关联：REQ-2026-009 / AC-007。
- 层级与目标：HTTP/OIDC 集成；网关回调。
- 依赖与前置：使用无会话窗口；仅使用本轮测试授权请求。
- 输入：虚构 code/state、错误 state、已消费的回调。
- 步骤：
  1. 未发起登录，直接请求带虚构参数的回调。
  2. 发起一次本轮登录，改变返回的 state，检查结果。
