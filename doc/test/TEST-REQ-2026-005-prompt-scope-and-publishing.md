## 4. 测试用例

### TC-001 类型创建、详情、筛选与历史快照

- 优先级：P0
- 关联需求/验收标准：REQ-001 / AC-001 至 AC-004
- 测试层级：Controller / Service / MySQL / Saber
- 目标模块与入口：提示词列表、创建、编辑、详情、版本接口和页面。
- 依赖与前置条件：用户 A 具备查看、新增、编辑、发布权限和 OWN 范围。
- 测试数据：GENERAL、SYSTEM、TEXT、IMAGE 及非法类型 UNKNOWN。
- 步骤：1. 分别创建四种合法类型；2. 查询详情和列表类型名称；3. 按类型筛选；4. 发布 V1 后修改类型并发布 V2；5. 提交 UNKNOWN。
- 可观察预期：合法类型保存并返回稳定编码和中文名称；筛选只返回范围内匹配类型；V1 保持原类型且 V2 使用新类型；非法类型返回 48012 且数据不改变。
- 证据：请求响应、主表/版本表只读快照、Saber 列表与版本截图。
- 清理：删除从未发布草稿；有版本记录按测试租户治理流程登记。

### TC-004 自动发布原子失败与并发冲突

- 优先级：P0
- 关联需求/验收标准：REQ-002 / AC-007
- 测试层级：Service / MySQL / 集成

- 依赖与前置条件：可注入版本插入失败、主表更新失败；两个客户端持有相同 lockVersion。

- 清理：恢复故障注入配置，保留成功版本用于后续用例。
